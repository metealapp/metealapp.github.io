개인정보처리방침

Meteal 앱의 개인정보 처리 방침

📅 최종 업데이트: 2026-05-12

1. 수집하는 정보

1-1. 직접 수집하지 않는 정보

이름, 이메일 주소, 전화번호 등 개인 식별 정보를 직접 수집하지 않습니다.

1-2. 자동으로 처리되는 정보

광고 ID, 기기 정보(모델, OS 버전), IP 기반 대략적인 위치, 광고 상호작용 데이터

1-3. 사용자 설정 데이터

등록된 지역, 그룹, 앱 설정 등은 기기 내 SQLite DB에 로컬 저장됩니다. 개발자 서버에는 수집되지 않습니다.

2. 데이터 사용 목적

날씨 정보 제공 / 지역 검색 기능 / 광고 표시 / 앱 안정성 개선

3. 제3자 서비스

아래 제3자 서비스가 데이터를 처리할 수 있습니다.

Google AdMob 광고/분석
Privacy Policy ↗
Open-Meteo 날씨 데이터
open-meteo.com ↗
GeoNames 지역 검색
geonames.org ↗

4. 위치 정보

GPS 또는 ACCESS_FINE_LOCATION 권한을 사용하지 않습니다. 사용자가 직접 선택한 지역의 좌표만 날씨 조회를 위해 Open-Meteo API에 전달됩니다.

5. 데이터 보존

사용자 설정 데이터는 기기에만 저장되며, 앱 삭제 시 함께 삭제됩니다. 제3자 서비스는 각자의 개인정보 처리 방침을 따릅니다.

6. 아동 개인정보 보호

이 앱은 아동을 대상으로 하지 않습니다.

7. 보안

개발자가 운영하는 별도의 서버가 없으므로, 사용자 데이터는 기기 내에만 보관됩니다.

8. 면책 조항

날씨 데이터는 제3자 서비스(Open-Meteo)에서 제공되며, 정확성을 보장하지 않습니다.

9. 방침 변경

본 방침은 변경될 수 있으며, 앱 또는 앱 스토어를 통해 공지됩니다.
